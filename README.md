## Overview
Exploratory Data Analysis projects using Python, R, and SQL to understand data structure, generate summary statistics, and detect anomalies.  
Each project demonstrates data cleaning, validation, and a clear workflow from raw data to insight ready outputs.  
Designed for Data Analyst portfolios and interview discussion.

## Objectives
- Understand dataset structure and quality
- Produce clear and reproducible summary statistics
- Detect outliers, inconsistencies, and anomalies
- Translate raw data into analysis ready datasets
- Communicate insights through SQL queries and BI visuals

## Industries Covered
- Healthcare
- Operations, Supply Chain and Logistics
- E Commerce, Marketing, Sales, Retail and Social Media
- Technology
- Sport
- Additional industries added over time

Each industry includes at least two independent EDA projects.

## Repository Structure
```txt
EDA-DA-Project/
├── Healthcare/
│   ├── breast-cancer-eda/
│   ├── dentistry-personnel-eda/                 
│   └── us-chronic-disease-eda/
│
├── E-Commerce, Marketing, Sales, Retail & Social Media/
│   ├── coffee-vending-eda/
│   ├── sales-insights-eda/
│   └── size-fit-return-prediction/
│
├── Operations, Supply Chain & Logistics/
│   └── shipping_bottleneck_analysis/
│
├── Technology/
│   └── app-store-performance-analyser/
│
├── Sport/                   
│
└── README.md ← You are here
```

Each project folder typically contains:
- `data/raw` for source data
- `data/processed` for validated datasets
- `sql` for analysis queries
- `scripts` or `scr` for Python or R analysis
- `visuals` or `outputs` for charts and outputs
- `tableau` for dashboard
- `database` or `db` for database for sql
- `tests` for any test of code
- `docs` for standard documents, data dictionary and powerpoints
- `README.md` with project specific context and findings
- `requirement.txt` for the libaries requirement for the code
